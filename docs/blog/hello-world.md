# 你好，世界

这是 **DeepSucker** 博客的第一篇文章。🎉

## 为什么写博客

写博客是一件「长期主义」的事。它帮我：

- **梳理思路**：把模糊的想法写成文字，往往能发现逻辑漏洞
- **沉淀知识**：三个月前的自己写的东西，现在的自己也能看懂
- **建立表达**：写作是最便宜的公开表达练习

## 这个博客的技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| 框架 | [VitePress](https://vitepress.dev/) | Vue 驱动的静态站点生成器 |
| 内容 | Markdown | 纯文本，版本管理友好 |
| 托管 | Cloudflare Pages | 免费、全球 CDN、速度快 |
| 域名 | deepsucker.top | 已经在 Cloudflare 上 |
