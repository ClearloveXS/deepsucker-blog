## 为什么写博客

写博客是一件「长期主义」的事，虽然我自己经常三天打鱼两天晒网。它帮我：

- **梳理思路**：把模糊的想法写成文字，往往能发现逻辑漏洞 —— 就像照镜子，越照越觉得自己丑
- **沉淀知识**：三个月前的自己写的东西，现在的自己也能看懂（偶尔）
- **建立表达**：写作是最便宜的公开表达练习，比发朋友圈安全，比表白成功率高

## 这个博客的技术栈

| 组件 | 选型 | 说明 |

## 写点代码试试

```ts
function hello(name: string): string {
  return `你好，${name}！欢迎来到 DeepSucker。别光看，点个收藏啊。`
}

console.log(hello('世界'))
// => 你好，世界！欢迎来到 DeepSucker。别光看，点个收藏啊。
```

> 注释：`console.log` 是前端最诚实的地方，它会把所有秘密都打在页面上 —— 包括你偷偷搜过的关键词（如果你用了某些浏览器插件的话）。
