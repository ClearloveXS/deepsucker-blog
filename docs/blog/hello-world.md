## 写点代码试试

```ts
function hello(name: string): string {
  return `你好，${name}！欢迎来到 DeepSucker。`
}

console.log(hello('世界'))
// => 你好，世界！欢迎来到 DeepSucker。
```

> 注释：`console.log` 是前端最诚实的地方。它会把所有不可告人都打在页面上——包括你偷偷搜过的关键词。如果你用了某些浏览器插件的话，它还会打出你的小秘密。
