# 关于我

你好，欢迎来到 **DeepSucker**。

这里是我记录生活与技术的个人空间。你可以把它理解成：一个会写代码的人，在深夜里对着屏幕自言自语的地方。有时候他在说话，有时候他只是在呼吸。

## 我在做什么

- 写代码、读文档、折腾各种工具 —— 顺便和 `node_modules` 相爱相杀
- 观察生活，记录思考 —— 尤其是那些「当时没想明白，现在也还没想明白」的事
- 相信「输出」是最好的「输入」 —— 虽然我的输出频率约等于我的恋爱频率

## 关于这个名字

**DeepSucker**，字面意思：深度吸吮者。

- **Deep**：因为我思考问题喜欢钻牛角尖，钻到后来自己都出不来了
- **Sucker**：因为我是各种订阅服务、付费墙和「再玩一局」的忠实 sucker

合起来就是：一个钻得深、陷得也深的家伙。深到什么程度呢？深到我有时候觉得自己是个洞。
